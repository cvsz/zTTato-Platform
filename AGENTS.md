# Agent System Rules

- Explain work and write developer-facing documentation primarily in Thai; keep code, commands, variables, protocol names and API routes in English.
- Never copy tokens, cookies, personal data or secrets from source repositories.
- Use official TikTok OAuth and Content Posting API rather than browser-based username/password automation.
- Require current creator-info and explicit consent for every direct post; preserve idempotency.
- Never claim production readiness without CI, verified domain, real sandbox recording, isolated backup/restore, legal review and release evidence.
- Do not submit the TikTok app for review or deploy to production without authorization.
